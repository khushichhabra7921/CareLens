# Analyses

Eight analyses, written as plain SQL in `sql/analyses/` (each file starts with its question,
method, assumptions and limitations). Each runs once per data load into a materialized view in the
`reporting` schema, the only clinical data the web app can read. Every number below comes from
`scripts/export_findings.py` running on the full synthetic dataset.
